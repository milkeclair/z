# z-ls

VS Code で Zsh スクリプトを書くための拡張機能です。関数名の補完、定義への移動、引数の案内、診断を利用できます。

## 主な機能

- 関数名の補完と、関数の定義への移動。
- ホバーで関数の説明、引数、戻り値、使用例を確認できます。呼び出しの入力中は引数のヘルプが表示されます。
- 未定義の関数、必須引数の不足、未使用の関数引数などを診断。

## 設定

| 設定 | 内容 |
| --- | --- |
| `z-ls.zPath` | フォルダーを開かずに編集するときに参照するディレクトリ。既定値は `~/.z` です。 |
| `z-ls.completion.showPrivateFunctions` | 非公開関数を補完候補に表示します。既定では無効です。 |
