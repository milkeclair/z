# z-ls

VS Code で Zsh スクリプトを書くための拡張機能です。関数名の補完、定義への移動、引数の案内、診断を利用できます。

## 使い始める

VS Code の拡張機能ビューで `z-ls`（発行者 `milkeclair`）をインストールします。プロジェクトのフォルダーを開き、`.zsh` ファイルを編集してください。

## 主な機能

- 関数名の補完と、関数の定義への移動。
- ホバーで関数の説明、引数、戻り値、使用例を表示。入力中は署名ヘルプで引数を確認できます。
- 未定義の関数、必須引数の不足、未使用の関数引数などを診断。

## 設定

| 設定 | 内容 |
| --- | --- |
| `z-ls.zPath` | フォルダーを開かずに編集するときに参照するディレクトリ。既定値は `~/.z` です。 |
| `z-ls.completion.showPrivateFunctions` | 非公開関数を補完候補に表示します。既定では無効です。 |

## 文字列内のZshコードを編集する

Zsh コードを受け取る引数に、関数コメントで `[code]` を指定すると、文字列内でも補完、定義への移動、色分けを利用できます。

```zsh
# $1 [code]: 実行するZshコード
run_code() {
  eval "$1"
}

# $1: 表示するメッセージ
say() {
  print -r -- "$1"
}

run_code 'say "hello $USER"'
```

たとえば、`run_code` に渡す文字列の中で `say` を補完できます。`[code | 'noop']` のように指定すると、`noop` は通常の文字列として扱われます。
